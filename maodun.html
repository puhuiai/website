猫盾 Maodun 5.0

面向 Windows 的 AI Agent 规范监视器。发现本机运行的智能体、工作流与知识库，记录行为，管理授权，并对高风险操作进行分级处置。目标智能体不需要修改源码。

Windows 10/11v5.0.0本地行为审计
下载安装包GitHub 说明

自主发现

扫描本机 AI Agent、工作流与知识库，自动加入监控列表。

权限管控

按时间、目录和权限范围授权，并可随时撤销。

行为记录

记录关键运行事件，让自动化操作有迹可查。

风险处置

高危操作二次确认，AI 发起的删除与覆盖必须经过用户确认。

适用场景

适合在个人开发机、企业工作站和自动化实验环境里运行 AI Agent 的用户。猫盾关注智能体行为与权限边界，不替代杀毒软件或终端安全套件。

安装方法

下载安装程序，按提示完成安装。首次启动时选择需要监视的目录与授权范围。若安全软件拦截，请先核验安装包来源和数字签名信息。
