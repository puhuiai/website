龙虾 Pro 3.0

面向 Windows 的 AI Agent 桌面工作台。连接大模型、任务流程和本地工具，用自然语言组织复杂任务。支持 OpenAI 兼容接口、DeepSeek 和本地 Ollama。

Windows 10/11v3.0.0OpenAI 兼容Ollama
下载安装包GitHub 说明

统一模型入口

配置 OpenAI 兼容接口或 DeepSeek 等模型服务。

本地模型

可连接本机 Ollama，适合隐私敏感或离线优先的任务。

工作流编排

把模型、工具和任务步骤放到同一个桌面工作台中。

系统要求

Windows 10/11 64 位，8GB 内存起，推荐 16GB。需要能访问所选模型服务，或在本机运行 Ollama。

费用说明

软件免费使用。调用第三方模型 API 产生的费用由用户自己的服务账号承担。
